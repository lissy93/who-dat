            终端接口
          

          无需密钥
        

        
页面和接口在同一部署上。浏览器打开根路径看到这个界面；curl 打下面的路径拿到 JSON。不需要 API key，响应带 CORS。

        

          

            
            bash — wi.fs.kg
          

          

        

        
    
          
  • 单条查询走 /v1/whois/{domain}，裸路径 /{domain} 也行。加上 ?raw=true 返回上游 RDAP JSON 或 WHOIS 原文。
    • 
          
  • 批量用 /multi?domains=a.com,b.com。默认最多 10 个，可用环境变量 MAX_DOMAINS 调整。
    • 
          
  • 完整字段说明在 /docs。OpenAPI 规范在 /openapi.yaml。

            数据与限制
          

        

        
    
          
  • 先问 RDAP。只有这个后缀没有 RDAP 服务器时，才退回端口 43 的 WHOIS。
    • 
          
  • 两种来源收成同一套字段：是否注册、注册商、日期、状态码、名称服务器、DNSSEC、联系人。
    • 
          
  • 速率看部署方式。放在 Vercel 上时，匿名访问默认大约每分钟 30 次。
    • 
          
  • 这是注册信息，不是「这个站安不安全」的结论。页面不加载广告或统计脚本。

            常见问题
          

        

        

          怎么查一个域名的注册信息？
          
在上方输入域名，例如 example.com，或点一个示例。也接受带 https:// 的地址，服务端会先剥掉协议和路径。页面请求本站的 /v1/whois/{domain}，把注册状态、注册商、日期、名称服务器和联系人摊开。

        

        

          为什么联系人经常是空的？
          
多数注册局按隐私规则隐去个人联系信息，通用顶级域尤其常见。隐去时这一格会写「已隐去」。那是注册局的选择，不是查询失败。

        

        

          可以在命令行里查吗？
          
可以，不需要密钥。请求 /v1/whois/example.com 得到归一化 JSON；加上 ?raw=true 则是上游原文。多个域名用 /multi?domains=a.com,b.com。完整地址在上面的终端示例里。浏览器访问根路径仍然是这个页面。

        

        

          会记录我查过什么吗？
          
页面没有第三方统计。「最近」列表只存在你这台浏览器的本地存储里，可以在上面一键清除。服务端可以开内存缓存，用来少打注册局，缓存的是查询结果，不是一份用户档案。
